# Projet Bank Marketing

## Contexte du projet
Ce projet utilise PyCaret pour analyser le dataset Bank Marketing UCI, visant à prédire la souscription de dépôts à terme. Le dataset provient d'une banque portugaise et contient des informations détaillées sur les campagnes de marketing direct menées par téléphone.

## Données
Le dataset contient divers attributs des clients, tels que :
- Âge
- Type d'emploi
- Niveau d'éducation
- État civil
- Type de communication
- Durée du dernier contact
- Nombre de contacts de la campagne
- Résultat de la campagne précédente

## Algorithmes utilisés
Nous utilisons PyCaret pour automatiser le processus de machine learning, y compris :
- La configuration de l'environnement
- La comparaison de modèles
- L'optimisation des hyperparamètres
- L'évaluation des modèles

## Conclusion
Ce projet permet de comprendre quelles caractéristiques des clients sont prédictives d'une souscription réussie à un dépôt à terme, aidant ainsi à adapter plus efficacement les stratégies de marketing.
